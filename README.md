# 个人记账 API —— 接口自动化测试

> 对一个 Python FastAPI 记账服务的接口测试实践：pytest + requests 构建 149 条用例，
> 用**边界值系统性探测**挖出 8 个缺陷（含 1 个安全级）。

---

## 三、测试设计思路

### 3.1 用例分层

| 层次 | 内容 | 条数 |
|---|---|---|
| 冒烟 | 健康检查、服务存活 | 4 |
| 鉴权 | 注册/登录/token 有效性/越权 | 20+ |
| 字段校验 | 用户名/密码/邮箱/金额/日期/类别的边界与非法值 | 80+ |
| 业务 | 交易增删改查、统计聚合、过滤分页 | 40+ |

### 3.2 核心方法：**边界值逐层向上探测**

不预设上限，从正常值一路试到极端值，找到"规则画在哪"。

```
密码长度：8 → 9 → 72 → 73 → 100 → 4096 → 4097
金额大小：0.001 → 1e6 → 1e12 → 1e100 → 1e300 → 1e308 → 1e400
邮箱长度：64 → 65 → 254 → 255
日期范围：0001-01-01 → 1900 → 2036 → 9999-12-31
```

## 四、发现的 8 个缺陷

| 编号 | 缺陷 | 级别 | 发现方式 |
|---|---|---|---|
| DEF-001 | **密码超过 72 字节被 bcrypt 截断，不同密码可互相登录** | 安全 | 边界值 + 攻击性构造（用 `72a+XXXX` 注册、`72a+YYYY` 登录，返回 200） |
| DEF-002 | 密码超 4096 位返回 500（应为 422） | 严重 | 边界值 + 状态码语义 |
| DEF-003 | 金额无上限，1e308 可写入 | 一般 | 边界值探测 |
| DEF-004 | 金额累加溢出导致统计返回 `null`（HTTP 200 但契约破坏） | 严重 | 跨接口联动验证 |
| DEF-005 | 交易日期无范围校验（公元 1 年、9999 年均可写入并污染统计） | 一般 | 边界值 + 联动 |
| DEF-006 | 金额 float 精度漂移（0.1 + 0.2 ≠ 0.3） | 一般 | 已知缺陷模式 + 实测 |
| DEF-007 | 邮箱 local 部分 65 字符超出 RFC 5321 上限仍被接受 | 一般 | 规范比对 + 边界值 |
| DEF-008 | 同一参数 `month` 在两个接口校验规则不一致（一个报错、一个静默返回 0） | 一般 | 一致性对比 |

### 重点缺陷说明

**DEF-001 密码截断（安全级）**

```python
# 1. 用 72 个 a + XXXX 注册
# 2. 用 72 个 a + YYYY 登录 → 返回 200，登录成功
# 结论：bcrypt 只取前 72 字节，两个不同的密码等价
```

**DEF-004 统计溢出（隐蔽级）**

```python
# 造两笔 1e308 的交易 → GET /stats
# 返回 {"total_expenses": null, "total_number": 2, "max_amount": 1e+308}
# 状态码 200，但字段为 null → 前端会崩
```

## 五、如何运行

```powershell
cd api_test

# 安装依赖
pip install -r requirements-test.txt

# 全量执行
pytest -v

# 只跑字段校验
pytest tests/test_03_register_validation.py -v

# 生成 HTML 报告
pytest --html=report.html --self-contained-html
```

**预期结果**：`143 passed, 6 xfailed`

> 6 个 xfail 是**已知未修复缺陷**，用 `@pytest.mark.xfail` 标记，
> 修复后会自动变成 XPASS，提醒更新用例。

## 六、测试结论

1. 接口基本功能完整，鉴权与 CRUD 主流程可用。
2. **输入校验薄弱是核心问题**：密码、金额、日期、邮箱均缺少边界与范围校验（6 个缺陷集中于此）。
3. **状态码语义不规范**：参数超限抛 500 而非 422，业务错误与系统错误混用。
4. **存在安全风险**：bcrypt 截断导致密码等价，属可被利用的安全缺陷，建议优先修复。
5. 建议：引入 Pydantic 的字段级校验（`constr(max_length=72)`、`condecimal(gt=0)`），
   统一异常处理返回 422 + 字段级错误信息。
